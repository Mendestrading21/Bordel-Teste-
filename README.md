# Bordel-Teste-

Dépôt d’incubation pour les nouveaux projets personnels d’Elio Mendes.

## Organisation

Chaque projet doit vivre dans son propre dossier sous `projects/<nom-du-projet>/` et conserver ses règles Claude Code dans `.claude/skills/`.

## Règles générales

- aucun secret, mot de passe bancaire ou token API dans Git ;
- une branche dédiée par lot de travail ;
- une Pull Request brouillon avant toute fusion ;
- aucune fusion sur `main` sans validation explicite ;
- chaque projet possède son propre `README.md` et son propre `STATUS.md`.
