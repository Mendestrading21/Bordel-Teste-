# Captures — Lot 10

Modification d'une position, ajoutée au Lot 10 : c'est le parcours critique
n° 10 de `QUALITY_GATES.md` (« modification et suppression d'une position »),
dont seule la suppression existait.

| Fichier                                  | Taille      | Écran                                |
| ---------------------------------------- | ----------- | ------------------------------------ |
| `mobile-390x844-modifier-position.png`   | 390 × 1150  | Fiche de position, bloc « Modifier » |
| `desktop-1280x900-modifier-position.png` | 1280 × 1100 | Le même en large                     |

Ni l'instrument ni le compte ne sont modifiables, et l'écran dit pourquoi :
les changer réécrirait le passé de la position, dont les points d'historique
ont été calculés sur le titre d'origine.

Le rond en bas à gauche est l'indicateur de `next dev` : ces captures viennent
du serveur de développement, seule configuration où le mode démonstration est
autorisé.

Toutes les données sont fictives.
