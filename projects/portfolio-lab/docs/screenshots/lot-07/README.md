Les cinq étapes se dévoilent l'une après l'autre. La fiche de vérification
affiche le symbole canonique, le multiplicateur, la devise, les jours restants,
bid/ask/dernier échange, le prix retenu et **la méthode de valorisation** — avec,
le cas échéant, le motif ayant écarté le milieu de fourchette.

Toutes les données sont fictives : sous-jacent `DEMOT`, cotations inventées.
