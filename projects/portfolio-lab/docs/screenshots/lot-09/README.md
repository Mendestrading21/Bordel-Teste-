Sauvegarde, suppression définitive et dégradation hors ligne.

Le bandeau hors ligne est la pièce qui rend le cache honnête : sans lui,
l'utilisateur lirait un patrimoine daté en croyant le voir à l'instant. L'âge
affiché vient de l'horodatage inscrit par le serveur dans la page elle-même —
une page sortie du cache a été rendue à un moment que le navigateur ne connaît
pas autrement.

Le bouton de suppression reste inactif tant que le mot n'est pas recopié
exactement. Le serveur revérifie ce mot : une garde purement visuelle se
contourne en une requête.

Le rond en bas à gauche est l'indicateur de `next dev` : ces captures viennent
du serveur de développement, seule configuration où le mode démonstration est
autorisé.

Toutes les données sont fictives.
